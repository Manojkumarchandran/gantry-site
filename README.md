# Gantry

Official website of **Gantry**, a small software studio in Theni, Tamil Nadu, India.

We build websites, mobile and web apps, business software and AI automation for growing businesses. We are also building our own products from the problems we keep solving for clients.

## About this site

- Single-page static website (HTML and CSS only)
- Responsive, so it works on phones, tablets and desktops
- No build step and no dependencies

## Files

| File | Description |
|---|---|
| `index.html` | The complete website |

## Run locally

Download the files and double-click `index.html` to open it in your browser.

## Deploy

The site is hosted on [Vercel](https://vercel.com). Every change pushed to this repository is deployed automatically.
